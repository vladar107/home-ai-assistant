# Security Policy

This is a private household project. Please report vulnerabilities privately
through GitHub's private vulnerability reporting: open the repository's
Security tab and choose "Report a vulnerability". Do not open public issues for
security problems.

Helpful details:

- the affected component or file
- steps to reproduce
- the impact you expect

Email addresses, phone numbers and calendar street addresses reach the model
provider only as placeholders; a way past that, beyond the limits listed under
"Personal values behind placeholders" in `docs/architecture.md`, is in scope.

There is no bounty. Responses are best-effort.

Only the latest commit on `main` is supported.
